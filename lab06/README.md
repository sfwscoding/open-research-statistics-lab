# Lab 06 — การวิจัยเชิงออกแบบทางการศึกษา (ฉบับอ่านเพื่อศึกษา)

**รีเซ็ตระบบวันที่ 2 พฤศจิกายน 2569** — ใช้ไฟล์ต้นฉบับที่ผู้ใช้ส่งมา `educational-design-research-b-total.pdf` (1,128 หน้า) เทียบข้อความหน้า PDF แบบหน้า-ต่อ-หน้า

## จุดประสงค์

- ฉบับ A ภาษาไทยล้วน และฉบับ B อังกฤษ–ไทยเทียบเคียง **สร้างจากแหล่งข้อมูลคำแปลรายหน้าเดียวกัน**
- ใช้ **เลขหน้า PDF** เป็นตัวอ้างอิงหลัก; บางหน้ามีเลขพิมพ์ของหนังสือต่างจากเลขหน้า PDF
- **ไม่ย่อ ไม่ข้ามบท ไม่สร้างคำแปลจากสรุป**; สถานะ `translated_first_pass` หมายถึงแปลรอบแรก ไม่ใช่ผ่านการพิสูจน์อักษรวิชาการ
- ภาพปก ภาพ ตารางและสมการที่จะต้องยกมาใหม่ใน HTML ต้องจัดการแยกเป็นส่วนประกอบของหน้าที่เกี่ยวข้อง หากยังไม่มีให้ระบุเชื่อมกลับสู่ต้นฉบับ ไม่อ้างว่าได้ถอดครบ

## สถานะจริง

- หน้า PDF ที่มีไฟล์คำแปลแล้ว: **1, 2, 3, 4** จาก **1,128**
- หน้าถัดไปที่ต้องดำเนินการ: **PDF หน้า 5**
- อ่าน HTML: [เปิดตัวอ่าน](reader.html?page=1&view=a) | [สองภาษา](reader.html?page=1&view=b)
- ตรวจสถานะ: [manifest.json](manifest.json)

## โครงสร้าง

- `manifest.json` บันทึกจำนวนหน้าต้นฉบับ หน้าที่แปลแล้วและหน้าถัดไป
- `pages/0001.json`, `pages/0002.json`, ... เก็บเนื้อหา `en` และ `th` ที่คู่กันในแต่ละช่วงข้อความ
- `reader.html` อ่านข้อมูล JSON หน้าเดียวและแสดงได้ทั้งสองมุมมอง ปุ่มบันทึกเป็น PDF พิมพ์เฉพาะหน้านั้น
- `../lab06.html` หน้าแรกสำหรับนำทางมายังตัวอ่าน

## ขั้นตอนสำหรับหน้าต่อไป

1. เปิด **PDF ต้นฉบับหน้า N**; ตรวจเนื้อหาที่เป็นข้อความ ตาราง และรูปภาพกับหน้าเอกสารจริง
2. บันทึกหัวข้อและเนื้อหา `en`/ `th` ให้ครบตามลำดับเดิมใน `pages/NNNN.json`
3. ตรวจความหมายศัพท์เฉพาะ ชื่อคน ตัวเลข และหมายเลขหน้า; ถ้าข้อความอ่านไม่ได้ให้ระบุไม่ชัดเจนไว้
4. แก้ `manifest.json` ให้ตรง **เฉพาะหน้าที่เสร็จจริง** แล้วตรวจหน้าแสดงผล A/B
5. แจ้งผู้ใช้อย่างตรงไปตรงมา: หน้าใดที่ทำแล้ว และหน้าใดที่ยังไม่ได้ทำ
