## หลักการควบคุมคุณภาพ
1. ตรวจข้อความทั้งบทจาก PDF ฉบับผู้ใช้พร้อมเลขหน้า ทุกหัวข้อ ตาราง เชิงอรรถ และภาพประกอบ
2. แปลเนื้อหาเต็มไม่สรุปแทนคำแปล ตรวจชื่อผู้เขียนและตัวเลข; ศัพท์เทคนิคใช้สม่ำเสมอ
3. บันทึกข้อความอังกฤษและไทยในไฟล์เดียว แสดงเป็นสองฉบับจากข้อมูลเดียวกัน
4. ทำสรุปการศึกษาเป็นส่วนท้ายบท **แยกจากคำแปล**
5. อัปเดต `manifest.json` และหน้าแรกเมื่อทำบทนั้นเสร็จจริงเท่านั้น
6. บทที่ยาวเกินทำอย่างรอบคอบในครั้งเดียว ต้องระบุความคืบหน้าจริง ไม่แจ้งว่าเสร็จหากยังไม่เสร็จ
